## About The Project

This was one of the first arcade games I completed with the help of Java and the LibGDX framework! 

Control the snake with **WASD** press the period **( . )** button to restart!

## Getting Started

The repository comes with a compiled **JAR file**, and a **batch script** to run it

To play the game, simply have a valid installation of a [**Java Runtime Environment (JRE)**](https://www.oracle.com/ca-en/java/technologies/downloads/) and double-click on **SpaceSnake.bat**!

**Note**: If you are on Mac/Linux, simply navigate to your cloned repository's location and execute the desired batch script using the terminal. For example:

`java -jar SpaceSnake.jar`
